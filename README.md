# Hvildir

Side Quest for Your Life

하루에 하나의 작은 현실 모험을 제안하는 오프라인 우선 Android 앱입니다. Flutter/Dart로 만들었습니다. 가입, 광고, 인증과 미완료 불이익은 없습니다.

## 콘텐츠 작성

[lib/guild_content.dart](lib/guild_content.dart)의 `guildGreetings`, `guildReturnGreetings`, `quests`를 직접 수정합니다. 인사말과 퀘스트는 요청한 목록을 반영했습니다. 각 목록은 하나 이상이어야 하며 퀘스트는 `(제목, 설명)` 형식입니다. 공개 후 기존 퀘스트 순서를 바꾸거나 항목을 삭제하면 이미 저장된 오늘의 퀘스트가 바뀔 수 있으므로 기존 목록 뒤에 추가하세요.

## 실행과 빌드

Flutter stable과 Android Studio/Android SDK가 필요합니다. 이 작업 PC에서는 `.tools/flutter/bin/flutter.bat`을 사용할 수 있습니다. Android Studio에서 프로젝트 루트를 열고 Flutter 및 Dart 플러그인을 설정하거나 다음 명령을 실행합니다.

```powershell
.\.tools\flutter\bin\flutter.bat pub get
.\.tools\flutter\bin\flutter.bat test
.\.tools\flutter\bin\flutter.bat run
.\.tools\flutter\bin\flutter.bat build appbundle --release
```

릴리스 번들은 `build/app/outputs/bundle/release/app-release.aab`에 생성됩니다. 패키지 ID는 `com.questapp.littleadventure.little_adventure_guild`입니다. 앱 이름 Hvildir와 별개인 내부 식별자로, Play에 처음 등록한 뒤에는 변경할 수 없습니다.

## 서명 키

이 PC에서 생성한 업로드 키는 `android/app/upload-key.jks`, 비밀번호 및 설정은 `android/key.properties`에 있습니다. 두 파일은 Git에 포함하지 않습니다. **두 파일을 함께 안전한 별도 장소에 백업하세요.** 추후 앱 업데이트를 같은 업로드 키로 서명해야 합니다. 비밀번호나 키를 공개 저장소에 올리지 마세요.

## 현재 범위

- 퀘스트와 완료 상태는 기기에만 보관됩니다. 기기를 바꾸거나 앱 데이터를 삭제하면 기록이 사라집니다.
- 후원 및 의뢰 제안은 준비 중 화면이며 결제나 외부 폼은 연결되지 않았습니다.
- 로컬 알림은 구현하지 않았습니다. 날씨·위치 기반 추천은 Android에서 선택적으로 사용할 수 있습니다.
- `store-assets/`의 아이콘과 그래픽은 임시 이미지입니다. 화면 이미지는 디자인 렌더링이므로 Play 등록 전에 실제 기기에서 촬영한 스크린샷으로 교체하세요. 스토어 등록 문안과 최종 콘텐츠도 확인하세요.
- 비공개 테스트를 시작하기 전 Play Console의 앱 정보, 테스트 대상, 데이터 보안 및 정책 항목은 실제 앱과 계정 상태에 맞게 직접 작성해야 합니다.

## 골드와 길드 꾸미기

퀘스트 완료·실패는 사용자가 직접 선택하며 별도의 인증은 없습니다. 일반 의뢰를 완료하면 10 G, 어려운 의뢰를 완료하면 30 G를 지급합니다. 실패해도 보유 골드는 줄지 않고, 결과는 변경할 수 없습니다. 길드 꾸미기에는 각각 150 G인 장식 10개가 있으며 구매 후 켜거나 끌 수 있습니다. 같은 위치에 배치되는 장식을 켜면 기존 장식은 꺼집니다. 골드와 장식은 기기에 저장되며, 앱 데이터를 삭제하거나 다른 기기로 옮기면 자동으로 복원되지 않습니다.

## 의뢰 주기와 날씨

- 양피지를 누른 시점부터 정확히 24시간 동안 같은 의뢰가 유지됩니다. 열지 않은 양피지는 날짜가 바뀌어도 그대로 남습니다. 만료 후에는 앱을 사용하는 중이거나 다음에 접속했을 때 새 의뢰를 고릅니다. 인사는 별도로 기기의 달력 날짜 기준 하루 첫 접속에 표시합니다.
- 이전 버전에서 열린 시각이 저장되지 않은 의뢰는 업데이트 후 첫 실행 시각부터 24시간 유지합니다. 이미 받은 의뢰가 예기치 않게 바뀌지 않도록 하기 위한 처리입니다.
- Android에서 위치와 날씨를 선택적으로 사용할 수 있습니다. 허용한 경우 전경에서만 대략적인 위치를 확인하고, 위도·경도를 소수점 한 자리로 반올림해 [Open-Meteo](https://open-meteo.com/)에 날씨 조회를 요청합니다. 앱은 좌표를 저장하지 않습니다. 설정에서 끌 수 있으며, 이미 받은 의뢰는 설정 변경으로 바뀌지 않습니다.
- 날씨를 알 수 있으면 날씨가 필요한 의뢰의 조건을 적용하고, 조건 없는 일반·어려운 의뢰도 각각 같은 확률로 추첨합니다. 현재 시간대는 의뢰 추첨을 제한하지 않습니다. 위치 권한, 위치 서비스, 네트워크 또는 날씨 API를 사용할 수 없으면 전체 의뢰에서 동일한 확률로 선택합니다.
- 날씨 데이터 출처는 [Open-Meteo](https://open-meteo.com/), 라이선스는 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)입니다. 무료 API는 비상업적 사용과 요청량 제한이 적용되므로 배포 규모나 수익화 방식이 바뀌면 [이용 조건](https://open-meteo.com/en/terms)을 다시 확인해야 합니다.

## 첫 실행 안내

처음 실행하면 길드주인의 대화로 하루 한 의뢰, 완료·실패 보고, 인증 없는 신뢰 규칙, 골드와 길드 꾸미기를 안내합니다. 모든 이야기를 읽고 모험을 시작하면 완료 상태를 기기에 저장합니다. 앱 데이터를 삭제하면 안내가 다시 표시됩니다. 대사는 `lib/guild_content.dart`의 `guildTutorial`에서 수정할 수 있습니다.

첫 실행 안내가 끝난 날에는 별도의 일일 인사가 나오지 않습니다. 이후 일일 인사는 기기의 날짜를 기준으로 하루 첫 접속에만 표시되고, 같은 날 다시 앱을 열면 인사를 건너뜁니다. 인사를 본 날짜는 기기에 저장됩니다.

이전 방문 날짜와 오늘의 기기 날짜 차이가 3일 이상이면 오랜만에 온 인사 중 하나를 무작위로 고릅니다. 이전 방문 날짜를 알 수 없다면 일반 인사를 사용합니다. 방문 기록은 기기에만 저장됩니다.

## 글꼴과 움직임

앱은 Lee Minseo(quiple)의 Galmuri11을 사용합니다. 한글·라틴 문자·가나 및 일부 한자를 지원하며, 글꼴에 없는 문자는 기기의 대체 글꼴로 표시됩니다. 새 언어를 추가할 때는 해당 언어의 글리프와 가독성을 별도로 확인해야 합니다. 글꼴은 SIL Open Font License 1.1이며, 원문은 `assets/fonts/Galmuri-LICENSE.txt`와 앱의 길드 메뉴 > 오픈소스 라이선스에서 확인할 수 있습니다. 출처: https://github.com/quiple/galmuri

길드의 등불은 은은하게 깜빡입니다. 기기의 애니메이션 줄이기 설정이 활성화되면 이 효과를 멈춥니다.

## 언어 설정

한국어, 영어, 일본어, 중국어 간체, 힌디어, 스페인어를 지원합니다. 기본은 기기의 언어 설정을 따르고 해당 언어가 없거나 지원하지 않는 언어면 영어를 사용합니다. 중국어 기기 설정에는 간체 번역이 적용됩니다. 길드 메뉴의 설정에서 언어를 직접 고르거나 다시 기기 설정을 따르도록 바꿀 수 있습니다. 선택한 언어는 기기에 저장됩니다.

퀘스트와 인사말을 `lib/guild_content.dart`에 추가하거나 수정할 때는 한국어 원문을 키로 각 언어 번역을 추가해야 합니다. 화면 문구는 `lib/translations.dart`, `lib/translations_extra.dart`, 인사말은 `lib/greeting_translations.dart`, 퀘스트는 각 언어의 `lib/quest_translations_*.dart` 파일에서 관리합니다. 번역이 없으면 영어 번역 또는 원문이 표시됩니다. 중국어·힌디어의 일부 문자는 기기의 대체 글꼴로 표시됩니다.

퀘스트 303개의 제목과 설명은 영어·일본어·중국어 간체·힌디어·스페인어로 번역되어 있습니다. 새 퀘스트를 추가할 때도 각 번역 파일을 함께 갱신하세요.
